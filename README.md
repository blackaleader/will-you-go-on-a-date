# Will you go on a date with me? 💕

A cute, kawaii-style web page to ask someone out — inspired by soft pink sakura vibes and a fluffy cat.

## Features

- Floating sakura petals, hearts, and tiny paw prints in the background
- Central card with your cat photo and the big question
- **YES** — shows a happy success screen with extra particle burst
- **no...** — runs away when the cursor gets close (classic dodge button)

## Run locally

Open `index.html` in your browser, or use a simple local server:

```bash
npx serve .
```

Then visit the URL shown in the terminal (usually `http://localhost:3000`).

## Customize

- Replace `assets/cat.png` with your own photo
- Edit the question or success message in `index.html`
- Tweak colors in `css/style.css` (`:root` variables)

Good luck! 🌸
